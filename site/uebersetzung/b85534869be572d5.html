Netavo startet Software-BNG für Breitbandbetreiber

Original bei TelecomTalk lesen Netavo Launches Software BNG for Broadband Operators

Netavo hat die Breitband-Gateway-Software, die in seinem eigenen Netz zum Einsatz kommt, kommerziell veröffentlicht. Die Plattform läuft auf Standard-x86-Servern, kombiniert Teilnehmerverwaltung, Carrier-Grade NAT sowie Routing und bietet eine Lizenzierung auf Basis der gleichzeitigen Teilnehmerzahlen.

Der im Vereinigten Königreich ansässige Netzbetreiber und Softwarehersteller Netavo hat die kommerzielle Veröffentlichung von Netavo BNG, seiner Software für Broadband Network Gateway (BNG) und L2TP Network Server (LNS), bekannt gegeben. Das Unternehmen gibt an, dass die Plattform im vergangenen Jahr produktiv im eigenen Netz eingesetzt wurde und nun anderen Breitbandbetreibern zur Implementierung auf deren eigener Hardware zur Verfügung steht. Die Software vereint die Teilnehmerterminierung, Carrier-Grade Network Address Translation (CGNAT) und Provider-Edge-Routing auf Standard-x86-Servern. Für Breitbandbetreiber bietet dies eine softwarebasierte Möglichkeit, mehrere Netzwerkfunktionen innerhalb einer einzigen Plattform abzuwickeln.

Teilnehmerverwaltung, CGNAT und Routing in einer Plattform

Ein Broadband Network Gateway verwaltet Teilnehmerverbindungen innerhalb des Netzes eines Betreibers. Laut Netavo unterstützt die Software PPPoE-, IPoE- und L2TP-Verbindungen, bietet IPv4- und IPv6-Unterstützung und kann bis zu 100.000 gleichzeitige Teilnehmer aufnehmen. Integriertes CGNAT ermöglicht es mehreren Teilnehmern, sich öffentliche IPv4-Adressen zu teilen. Netavo integriert diese Funktionalität in jede Lizenz, und die Software kann auch als eigenständige CGNAT-Appliance betrieben werden. Die Routing-Fähigkeiten der Plattform umfassen BGP, MPLS Layer 3 VPNs, dienstspezifische Virtual Routing and Forwarding (VRF) Instanzen sowie eine Auswahl zwischen IS-IS oder OSPF. Die Teilnehmerauthentifizierung kann über RADIUS oder eine direkte SQL-Datenbankanbindung erfolgen, mit Accounting-Unterstützung via RADIUS oder Azure Service Bus.

Management-Tools und Bereitstellungsoptionen

Betreiber können Netavo BNG über eine REST-API, eine browserbasierte Schnittstelle mit Zwei-Faktor-Authentifizierung oder eine Befehlszeilenschnittstelle (CLI) im Junos-Stil verwalten. Die CLI unterstützt Konfigurations-Commits und Rollbacks, wodurch Betreiber Änderungen vornehmen oder zu einer früheren Konfiguration zurückkehren können. Netavo gibt an, dass die Datenebene den Datenverkehr weiterleitet, während die Steuerungsebene neu startet oder aktualisiert wird. Die Plattform bietet zudem zwei Forwarding-Backends: DPDK für Bare-Metal-Server und AF_XDP für Implementierungen, die virtuelle Maschinen, Labore und kleinere Standorte umfassen. Betreiber können das Backend entsprechend ihren Hardwareanforderungen auswählen.

Netavo meldet Kapazitäten von bis zu 200 Gbps

Netavo berichtet von einer Kapazität von bis zu 200 Gbps auf einem Server, der mit zwei 100-GbE-Schnittstellen ausgestattet ist, basierend auf eigenen Benchmarks bei aktivierter Quality of Service und CGNAT. Das Benchmark des Unternehmens misst die Verarbeitungskosten pro Paket und wendet einen Internet-Traffic-Mix an, um zu bewerten, ob die Software über ausreichende Verarbeitungskapazität verfügt, um beide Schnittstellen auszulasten. Das Benchmark ist in der kostenlosen Evaluierungsversion enthalten, sodass Betreiber die Leistung auf ihrer eigenen Hardware bewerten können.

Chris Byrd, Chief Technology Officer bei Netavo, erklärte, die Plattform sei entwickelt worden, um das eigene Netz des Unternehmens zu betreiben. Er fügte hinzu, dass Kunden dieselbe Software erhalten, die Netavo intern verwendet, wobei Carrier NAT in das teilnehmerbasierte Lizenzmodell integriert ist.

Teilnehmerbasierte Lizenzierung und kostenlose Evaluierung

Netavo BNG wird nach der Anzahl der gleichzeitigen Teilnehmer lizenziert, wobei alle Funktionen in allen Lizenzstufen enthalten sind. Das Unternehmen gibt an, dass keine separaten Gebühren für CGNAT, Routing oder Durchsatz erhoben werden. Betreiber können einen größeren Server installieren, um mehr Datenverkehr zu bewältigen, ohne die Lizenz ändern zu müssen, sofern sie innerhalb ihres Teilnehmerbereichs bleiben. Eine kostenlose Evaluierungsversion unterstützt bis zu 50 gleichzeitige Teilnehmer, enthält sämtliche Funktionen und ist zeitlich unbegrenzt. Optionale Pakete für den Produktionssupport reichen von Unterstützung während der Geschäftszeiten bis hin zu einer 24/7-Abdeckung mit garantierten Reaktionszeiten.
