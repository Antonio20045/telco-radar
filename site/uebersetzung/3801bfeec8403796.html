Microsoft hat gerade den tatsächlichen Azure-Umsatz in Dollar bekannt gegeben: 33,2 Milliarden US-Dollar

TechCrunch AI · 2026-10-28 · aus dem Englischen

Original bei TechCrunch AI lesen Microsoft just shared Azure’s actual revenue in dollars: $33.2 billion

Microsoft hat den Quartasumsatz von Azure noch nie in US-Dollar offengelegt. Normalerweise wurden lediglich ein Wachstumsprozentsatz genannt oder Meilensteine beim Umsatz auf vage Weise beschrieben. Doch am Mittwoch, als das Unternehmen ein weiteres Rekordquartal vorlegte, gab es bekannt, dass Azure im Quartal von Juli bis September einen beträchtlichen Umsatz von 33,2 Milliarden US-Dollar erwirtschaftet hat, was einem Anstieg von 48 Prozent gegenüber dem Vorjahreszeitraum entspricht.

Durch diese Offenlegung können Investoren die Leistung von Azure direkter mit Amazon Web Services und Google Cloud vergleichen, deren Muttergesellschaften ihre Cloud-Umsätze bereits jedes Quartal in US-Dollar ausweisen.

Alphabet, das ebenfalls am Mittwoch seine Bilanz vorlegte, gab an, dass Google Cloud im selben Quartal 30,7 Milliarden US-Dollar erwirtschaftet hat, womit Azure knapp vorne liegt. Berechnungen von TechCrunch zufolge hat Google Cloud, das auch die Workspace-Abonnements von Google umfasst, seinen Umsatz im Vergleich zum Vorjahr jedoch etwa verdoppelt und wuchs damit rund doppelt so schnell wie Azure.

Azure, eine Plattform, auf der Unternehmen Rechenleistung mieten, um Anwendungen und SaaS auszuführen sowie KI-Modelle zu erstellen und zu betreiben, ist nach unternehmenseigenen Angaben inzwischen Microsofts größte und wachstumsstärkste Produktlinie. Sie machte etwa 36 Prozent des quartalsweisen Gesamtumsatzes von Microsoft in Höhe von 92,3 Milliarden US-Dollar aus.

Der Umsatz von Azure lag zudem um rund 850 Millionen US-Dollar über den von Analysten erwarteten 32,3 Milliarden US-Dollar. Auch die Wachstumsrate von Azure in Höhe von 48 Prozent übertraf die Prognose von Microsoft-Finanzchefin Amy Hood, die diese bei der Bilanzkonferenz im Juli auf 44 bis 45 Prozent beziffert hatte.

Azure ist Teil von Agents and Infra, einem von zwei neuen Geschäftssegmenten, die Microsoft in diesem Quartal eingeführt hat. Zuvor hatte Microsoft über drei Segmente berichtet: Productivity and Business Processes, Intelligent Cloud sowie More Personal Computing. Das neue Segment Agents and Infra, in dem Azure mit dem Cloud-Geschäft von Microsoft 365 zusammengefasst ist, erwirtschaftete 76,8 Milliarden US-Dollar, was einem Anstieg von 25 Prozent gegenüber dem Vorjahr entspricht.

Amazon legt seine Bilanz am Donnerstag vor. Analysten erwarten auch bei dessen Cloud-Sparte Amazon Web Services ein Wachstum. Sie ist seit Anbeginn der größte Cloud-Anbieter, und niemand rechnet damit, dass Microsoft sie zum gegenwärtigen Zeitpunkt übertrifft. Da jedoch nun alle tatsächlichen Umsatzzahlen in Dollar vorlegen, ist das Rennen eröffnet.
