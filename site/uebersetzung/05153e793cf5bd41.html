Haben Sie den Google Chrome Browser? Löschen Sie diese Plugins sofort

Sage und schreibe 319 Erweiterungen für Google Chrome, die insgesamt 13,4 Millionen Mal heruntergeladen wurden, dienten dazu, Nutzer zu betrügen.

Einen neuen Bericht über gefährliche Erweiterungen für Google Chrome hat John Tucker von der Firma Socket veröffentlicht. Dies ist im Grunde eine Fortsetzung und zugleich eine Ausweitung einer früheren Untersuchung, bei der der Forscher 57 schädliche Plugins entdeckt hatte. Nun ist deren Zahl auf satte 319 gestiegen.

Gefährliche Erweiterungen für Chrome

John Tucker hat ganze 319 schädliche Erweiterungen für Google Chrome und andere Browser auf Chromium-Basis entdeckt. Sie wurden über 13,4 Millionen Mal heruntergeladen.

Diese Erweiterungen wurden von einer Handvoll organisierter Akteure erstellt, die von derselben Idee angetrieben wurden: unbemerkt die Kontrolle über die Standardsuchmaschine des Browsers zu übernehmen, jede Suchanfrage über einen verdächtigen Proxy-Server umzuleiten und auf Basis einer Partner-ID Affiliate-Provisionen von den Diensten Yahoo oder Bing zu kassieren.

Die Erweiterungen wirken nicht besonders bösartig. Sie leiten den Traffic der Browser-Nutzer über Server um, was Einnahmen für die Betrüger generiert. Der Forscher warnt jedoch, dass sich dies jederzeit ändern kann. Ohne jegliches Update könnten die Plugins damit beginnen, die Nutzer auf Phishing-Seiten umzuleiten, um Daten zu stehlen.

Wichtig ist, dass die meisten Erweiterungen bereits aus dem Chrome Web Store entfernt wurden, aber es werden ständig neue hinzugefügt. Sie werden unter anderem aktiv durch Werbung in sozialen Medien beworben. Die vollständige Liste der 319 schädlichen Plugins ist im Bericht der Firma Socket verfügbar.

Falls Sie eine davon installiert haben sollten, entfernen Sie diese am besten so schnell wie möglich und führen Sie einen vollständigen Scan mit einem Antivirenprogramm durch.
