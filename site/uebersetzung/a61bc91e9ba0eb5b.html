Microsoft wählt Intel Foundry für die Verpackung von Azure-Chips

Mobile World Live · 2026-11-19 · aus dem Englischen

Maschinelle Übersetzung. Dieser Text wurde automatisch aus dem Englischen übersetzt und nicht redaktionell geprüft. Verbindlich ist allein das Original.

Original bei Mobile World Live lesen Microsoft picks Intel Foundry to package Azure chips

Microsoft holt Intel Foundry an Bord, um das Advanced Packaging für seine eigenen Azure-Prozessoren zu übernehmen. Im Rahmen der Vereinbarung wird gleichzeitig eine mehrjährige Lieferung von Intel Xeon Serverprozessoren abgesichert. Durch das Abkommen ist Microsoft das erste Unternehmen, das öffentlich bekannt gibt, die EMIB-Packaging-Technologie (Embedded Multi-die Interconnect Bridge) von Intel für eigene Chips zu nutzen. Zudem wird die gemeinsame Arbeit an den Bereichen Arbeitsspeicher, Datenbankleistung und Sicherheit in ganz Azure ausgebaut. Finanzielle Konditionen und die Laufzeit des Abkommens wurden nicht genannt.

Die beiden Unternehmen planen zudem eine engere Zusammenarbeit bei der Azure-Roadmap und der auf Intel basierenden Azure-Hardware. Microsoft wird bei Xeon mit Compute Express Link (CXL) noch stärker mit Intel zusammenarbeiten, um die Speichernutzung in Azure zu optimieren. Die Unternehmen erklärten, dass Azure M-series v4 Virtual Machines (VMs), die CXL-Speicher und den Intel Flat Memory Mode in Xeon-6-Prozessoren nutzen, eine bis zu 2,3-fach höhere Leistung sowie eine größere Speicherflexibilität für anspruchsvolle Workloads bieten.

Die Unternehmen gaben an, dass die ersten Azure VMs mit Intel QuickAssist Technology (QAT) bis zu 2,5-mal schnellere SQL-Backups ermöglichen. Mit Intel Trust Domain Extensions (TDX) werden der VM-Speicher und der CPU-Registerstatus verschlüsselt, wenn vertrauliche VMs zwischen Hosts verschoben werden.

Saurabh Dighe, Corporate VP von Azure System and Architecture bei Microsoft, erklärte, Kunden benötigten „Infrastruktur, die um die für sie wichtigen Workloads herum aufgebaut ist“. Die Arbeit verbinde „Silizium- und Systementwicklung“ mit der wachsenden Nachfrage nach Cloud- und KI-Computing, so Dighe. Für Intel bedeutet dies einen namhaften Kunden in der Kundenliste für das Foundry-Packaging.

Naga Chandrasekaran, Chief Technology and Operations Officer sowie Leiter von Intel Foundry bei Intel, sagte, die KI-Infrastruktur entwickele sich zu immer komplexeren Systemen, die durch die gleichzeitige Optimierung von Silizium, Packaging, Rechenspeicher und Software entworfen würden. Er erklärte, dass EMIB „die Flexibilität der heterogenen Integration mit dem für die KI-Ära erforderlichen Fertigungsmaßstab“ verbinde.
