Funktioniert WLAN oder VPN nach dem Windows 11 Update nicht mehr? Microsoft erklärt, was sich geändert hat

Original bei ADSLZone lesen ¿No te funciona el WiFi o la VPN tras actualizar Windows 11? Microsoft explica qué ha cambiado

Wenn das Firmen-WLAN oder das Unternehmens-VPN nach der Installation des neuesten Windows-11-Updates keine automatische Verbindung mehr herstellt, sind Sie damit nicht allein. Eine von Microsoft mit den am 13. Oktober 2026 veröffentlichten Patches eingeführte Sicherheitsänderung modifiziert die Art und Weise, wie Windows bestimmte Anmeldeinformationen für die Verbindung mit Firmennetzwerken verwendet, was zu diesen Verbindungsausfällen führen kann. Das in Redmond ansässige Unternehmen hat dieses Problem des Updates KB5127648 am 15. Oktober in einem Authentifizierungshinweis eingeräumt. Die Änderung betrifft bestimmte Konfigurationen von Windows 11 24H2, 25H2 und 26H2 sowie Windows Server 2025. In den von Microsoft dokumentierten Fällen können die Zugangsdaten manuell eingegeben werden, um die Verbindung aufrechtzuerhalten. Microsoft hat einen Windows-11-Schutz geändert, ohne dass Administratoren etwas anpassen müssen. Der Ursprung des Problems liegt in einer veralteten Authentifizierungstechnologie namens NTLMv1. Obwohl Microsoft dieses Protokoll bereits aus neueren Windows-Versionen entfernt hat, nutzen bestimmte Unternehmensumgebungen nach wie vor von NTLMv1 abgeleitete kryptografische Mechanismen, um den Benutzer automatisch zu authentifizieren. Bis Oktober ließ Windows bestimmte Authentifizierungsversuche mit diesen Anmeldeinformationen zu. Seit dem 13. Oktober geht Windows jedoch dazu über, diese Versuche nicht mehr nur zuzulassen und zu protokollieren, sondern standardmäßig zu blockieren. Microsoft bezeichnet diese beiden Verhaltensweisen in seiner technischen Dokumentation als Audit und Enforce. Technische Details des Registrierungsschlüssels BlockNtlmv1SSO, einschließlich seines Speicherorts im System und der Auswirkungen der Werte 0 und 1 auf die Verwaltung von Anmeldeinformationen. In diesem Fall ist es nicht erforderlich, dass der Administrator eine Richtlinie ändert. Wenn der Registrierungswert BlockNtlmv1SSO nicht konfiguriert ist, wendet Windows intern den Modus Enforce an und blockiert die Verwendung von aus NTLMv1 abgeleiteten Anmeldeinformationen für das einmalige Anmelden (Single Sign-On), es sei denn, Credential Guard ist aktiviert. Dies sind die WiFi-, Ethernet- und VPN-Verbindungen, bei denen Fehler auftreten können. Microsoft hat bestätigt, dass bei drei Arten von Verbindungen in Windows 11 Fehler auftreten können: Unternehmens-WLANs, LAN-Verbindungen (Ethernet) von Firmen und VPNs, die eine auf MS-CHAPv2 basierende Authentifizierung verwenden. Hierbei handelt es sich um das System, das die Zugangsdaten in bestimmten Unternehmensumgebungen überprüft. In einigen Fällen verwendet Windows die Anmeldeinformationen, mit denen sich der Nutzer am Computer angemeldet hat, automatisch wieder. Genau das, was als einmaliges Anmelden oder SSO bekannt ist, kann den Fehler verursachen.
