Snapchat ermöglicht Entwicklern jetzt die Erstellung von AR Lenses mit KI-Assistenten wie Claude Code und Cursor

TechCrunch AI · 2026-11-18 · aus dem Englischen

Maschinelle Übersetzung. Dieser Text wurde automatisch aus dem Englischen übersetzt und nicht redaktionell geprüft. Verbindlich ist allein das Original.

Original bei TechCrunch AI lesen Snapchat now lets developers build AR Lenses with AI assistants like Claude Code and Cursor

Snapchat hat am Mittwoch angekündigt, dass es Lens-Erstellern die Möglichkeit bietet, Lenses mithilfe von KI-Programmierassistenten zu entwickeln, die sie bereits nutzen, wie etwa Claude Code, Cursor und Codex. Snapchat Lenses, die ein Kernbestandteil der Plattform des sozialen Netzwerks sind, sind AR-Effekte, die es Nutzern ermöglichen, ihr Aussehen zu verändern, digitale Objekte zu ihrer Umgebung hinzuzufügen oder über die Kamera mit animierten Erlebnissen zu interagieren.

Das Unternehmen führt Easy Lens CLI ein, das auf dem bestehenden Tool Easy Lens aufbaut, mit dem Ersteller Lenses über eine einzige Texteingabe im Web und auf Mobilgeräten generieren können. Easy Lens CLI überträgt diesen Ansatz in die bestehenden Arbeitsabläufe von Entwicklern und ermöglicht es KI-Assistenten, die technische Arbeit zu übernehmen, während sich die Ersteller auf die Vision der Lens selbst konzentrieren.

Die Einführung zeigt, dass Snapchat die Hürde für die Erstellung von AR-Inhalten senken und seine Plattform gleichzeitig für Entwickler zugänglicher machen möchte, die zunehmend KI-Programmierassistenten nutzen. Anstatt von Erstellern zu verlangen, den Umgang mit Snapchats eigenen Entwicklungswerkzeugen zu erlernen, integriert das Unternehmen die Erstellung von Lenses in die bereits genutzten KI-Programmier-Workflows, was wiederum den Kreis der Personen vergrößern könnte, die Inhalte für Snapchat entwickeln.

Entwickler, die am Lens+ Payouts-Programm von Snapchat teilnehmen, können mit den Lenses Geld verdienen, die sie mit Easy Lens CLI erstellen. Snapchat gibt an, im letzten Monat 1,8 Millionen US-Dollar an Community-Ersteller von Lens+ ausgezahlt zu haben.

Lens-Ersteller können die gewünschte Lens in einfacher Sprache beschreiben, und ihr KI-Assistent übernimmt den Prozess von Anfang bis Ende, so Snapchat. Dazu gehört das Bauen mit mehr als 100 AR-Bausteinen und 50 KI-Asset-Generatoren, das Erstellen von Vorschauen, das Veröffentlichen auf Snapchat und das Verfolgen ihrer Leistung.

Mit Easy Lens CLI können Entwickler nach Angaben von Snapchat alles erstellen, von Web Lens-Spielen mit Bestenlisten bis hin zu Kameraeffekten und Beauty-Filtern.

KI-Assistenten können Assets generieren, Lenses erstellen und testen, Fehler beheben und aktualisierte Versionen direkt an das Telefon des Erstellers senden. Die neue Funktion kann ein Spiel in einem einzigen Tag von einer ersten Idee zu einer veröffentlichten Lens machen, ohne dass Entwickler selbst Code schreiben müssen, so Snapchat.

Das Tool richtet sich an verschiedene Arten von Erstellern. Das Unternehmen weist darauf hin, dass Spieleentwickler bestehende Browserspiele als Web Lenses zu Snapchat bringen können, während KI-Ersteller Assets aus ihren bevorzugten Tools verwenden können, um Lenses in ihrem eigenen Stil zu erstellen. Darüber hinaus können Agenturen und Marken bestehende Kampagnen-Videos, Bilder und andere Marken-Assets mit geringerem Produktionsaufwand in AR-Erlebnisse verwandeln.

Easy Lens CLI läuft auf Mac, Windows und Linux.
